# Kenya Data Rights brand assets

These are the canonical project graphics supplied for Kenya Data Rights. They are reused across product surfaces without redrawing the logo.

- `kenya-data-rights-logo-transparent.png` — transparent full logo/wordmark for dashboard and compositing use.
- `kenya-data-rights-icon.png` — compact square mark for favicon, Android launcher and installer/executable packaging.
- `kenya-data-rights-logo.png` — full logo on a light background for documentation and presentation surfaces.

Platform-specific copies or resized/converted derivatives may be generated from these files as required by browsers, Android, Windows or macOS packaging. The underlying artwork should not be regenerated or stylistically altered without an explicit brand update.
