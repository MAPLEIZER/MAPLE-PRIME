# KDR Civic Participation

KDR can help discover official Kenyan public consultations affecting AI, cybersecurity, digital credit and data privacy, explain the material, and draft a memorandum from the user's own views.

## Anti-spam / authenticity rules

- official consultation sources only;
- recipients come from the official notice, never arbitrary user-supplied mailing lists;
- no background or bulk sending;
- no identity fabrication or rotation;
- one consultation is handled at a time;
- closed deadlines are clearly marked and submission actions are suppressed in the UI;
- email participation is generated as a `mailto:` draft so the user reviews and presses Send;
- official web forms are opened directly instead of automated submission/botting;
- future Gmail integration may create a draft, but should not silently send it;
- all generated text should reflect the user's stated views, not invent political positions.

This design supports individual civic participation while making automated flooding materially harder.
