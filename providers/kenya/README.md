# Kenya provider adapters

Each institution can have declarative metadata and, only where necessary, executable automation.

```text
providers/kenya/<slug>/
  metadata.yaml
  web_adapter.py       # optional
  selectors.json       # optional
  tests/
```

A website change must not alter the authoritative regulator observation. CAPTCHA failure becomes a manual action unless the user explicitly configures a lawful third-party solver.
